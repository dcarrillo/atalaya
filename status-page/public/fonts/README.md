# Self-hosted fonts

Latin subsets, downloaded from Google Fonts and served by the Worker's static assets.

- **Barlow** 400, 500 — https://fonts.google.com/specimen/Barlow
- **Barlow Condensed** 600, 700 — https://fonts.google.com/specimen/Barlow+Condensed
- **JetBrains Mono** 400, 500 — https://fonts.google.com/specimen/JetBrains+Mono

All three families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org/). The `.woff2` files are the Latin subsets published by
Google Fonts; no font files are requested from a CDN at runtime.
